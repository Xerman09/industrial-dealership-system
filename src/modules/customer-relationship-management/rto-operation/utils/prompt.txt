Executive Overview

The Retail Trade Outlet (RTO) Operation module is a mission-critical component of the SEA GAS Operations ecosystem. It governs the end-to-end distribution lifecycle between the main filling plant, City Dealers, and downstream Retail Trade Outlet agents.

The module enforces asset traceability, controlled circulation of LPG cylinders, and automated financial exposure tracking through real-time ledger computation and inventory synchronization.

At its core, the system is designed to eliminate leakage in cylinder circulation and enforce strict dealer accountability through data-driven controls.

2. Functional Scope and Boundaries
In Scope
Centralized registry of City Dealers and their assigned RTO agents
Territory-based assignment (barangay-level mapping)
Bulk delivery dispatch logging (full and empty cylinders)
Historical tracking of cylinder movement (fulls vs empties)
Real-time computation of:
Missing Tanks
Surplus Empties
Automated dealer ledger updates upon dispatch
Inventory synchronization with warehouse and return docks
Out of Scope
Financial settlement processing (handled by Finance/Reports Module)
Individual cylinder serial tracking (handled by Cylinder Tracking Module)
Return quality inspection and bad order processing
Banking/payment gateway integration

4. Core Business Logic
4.1 Automated Wholesale Billing (Price Snapshot Engine)

When a dispatch is recorded:

Total Charge = Full Cylinders Delivered × Wholesale Price (timestamp-locked)

Key principle:

The system applies a price snapshot at transaction time
Historical records remain immutable despite future price changes

This ensures financial audit integrity and prevents retroactive recalculation.

4.2 Asset Accountability Model
Core Formula
Missing Tanks = Total Fulls Delivered − Total Empties Returned
Surplus Handling Rule

If result is negative:

Convert to Surplus Empties
Example: -15 → “+15 Surplus Empties”

This prevents negative inventory distortion and improves interpretability.

4.3 Risk Threshold Control
If Missing Tanks > 100:
Dealer status → Critical Alert State
UI flagged (red-level escalation)
Delivery restriction may be enforced

This acts as a credit + asset risk containment mechanism.

8. System Constraints & Edge Cases
Constraints
Dealer must exist before transaction logging
Pricing strictly tied to global wholesale configuration
Credit limit enforced at transaction level
Edge Case Handling

A. Zero Movement Transaction

Input: 0 full, 0 empty
Result: Transaction ignored (no ledger pollution)

B. Credit Limit Breach

If transaction exceeds credit limit:
System blocks execution
Requires override authorization (Ops Manager/Admin PIN)

This enforces financial containment and controlled risk exposure.
